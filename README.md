# BidSmart Analytics (Online Bidding System)

BidSmart Analytics is an online auction marketplace for buyers, sellers, and administrators. It provides auction management, bidding workflows, notifications, and analytics dashboards.

## Features

- User registration and authentication
- Role-based access for buyers, sellers, and administrators
- Product listings and auction management
- Bidding and bid history
- Auction closure and winner determination
- In-app notifications
- Analytics dashboards and visualizations

## Technology Stack

- **Frontend:** React, Vite, Tailwind CSS, React Router, Axios, Recharts
- **Backend:** Python, FastAPI, Pydantic, SQLAlchemy
- **Database:** MySQL
- **Testing:** Pytest, Vitest, React Testing Library
- **Version Control:** Git and GitHub

## Project Structure

- `backend/` — Backend application
- `database/` — Database schema and related files
- `frontend/` — Frontend application
- `docs/` — Project documentation
- `BidSmart_Analytics_PRD.md` — Product Requirements Document

## Documentation

See `docs/` for the pre-project documentation in Markdown and PDF formats. The PRD contains detailed project requirements and specifications.

## Local Setup

1. Install the required Python and Node.js versions.
2. Configure the backend environment variables.
3. Set up the MySQL database using the provided schema.
4. Follow the setup instructions in the backend and frontend directories.
5. Start the backend and frontend using their documented commands.
